# Dhisme POS Roadmap

## MVP 1 — included in this starter

- Owner/seller login
- Product and stock list
- Owner product entry
- Customer entry
- Seller POS sale
- Cash/bank/mobile payment sale
- Credit-sale owner approval
- Daily cash closing
- Owner dashboard
- Basic audit log

- Sales history with invoice details
- Seller performance report
- Product sales report
- Customer debt payment collection
- Real-time owner alerts

- Offline sales draft queue
- Device/session tracking
- Store owner employee invitation flow
- Barcode scanning
- Receipt image attachments
- Backup/export to Excel
- Cloud functions for admin user creation
- Proper app signing and Play Store release
